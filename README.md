## 💻 How to Run Locally

You can open `index.html` directly in any web browser, or launch a lightweight local server:

### Option 1: Direct File Open
Double-click `index.html` or open with Google Chrome, Microsoft Edge, or Firefox.

### Option 2: Using Node.js (npx serve)
```bash
npm start
# or
npx serve -l 3000 .
```
Visit `http://localhost:3000` in your browser.

### Option 3: Using Python
```bash
python -m http.server 8000
```
Visit `http://localhost:8000` in your browser.

## 📦 Deployment to GitHub Pages

1. Initialize a git repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of IntradaySpell website"
   ```
2. Push to your GitHub repository:
   ```bash
   git remote add origin https://github.com/<your-username>/IntradaySpell.git
   git branch -M main
   git push -u origin main
   ```
3. In GitHub repo settings, go to **Pages**, select **Deploy from a branch (`main`)**, and save!
